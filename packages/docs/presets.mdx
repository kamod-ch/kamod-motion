Presets are plain data objects compatible with `Motion` and `Presence`. Import from `@kamod-ch/motion/presets`.

<ExampleFrame title="Scale preset" preview={<FadeScaleDemo />} code={fadeScaleDemoCode} />

## Available presets

- `fade`, `scale`
- `slideUp`, `slideDown`, `slideLeft`, `slideRight`
- `stagger(interval, startDelay)` — delay factory for list entrances
- `resolvePreset(preset, reducedMotion)` — pick the reduced fallback yourself for imperative calls

<CodePreview
  language="tsx"
  code={`import { Motion } from "@kamod-ch/motion/motion";
import { Presence } from "@kamod-ch/motion/presence";
import { slideUp } from "@kamod-ch/motion/presets";

<Presence show={open}>
  <Motion preset={slideUp} />
</Presence>`}
/>

`Motion` reads `preset.reduced` when reduced motion is active. `resolvePreset` remains for code that drives `animate()` directly.

Import `@kamod-ch/motion/presets/tokens.css` when your own CSS should share these durations and easings. Preset objects do not read the variables at runtime; they carry the same 250ms standard ease in JavaScript. The `prefers-reduced-motion` block in the stylesheet only shortens those CSS variables.
