## Checklist

- Use `useReducedMotion()` or the `reducedMotion` prop on `Motion` / `Presence`
- Prefer opacity-only fallbacks from `@kamod-ch/motion/presets` (`resolvePreset`)
- Do not auto-play infinite spatial loops without a pause control
- Pair enter/exit on focusable overlays with `@kamod-ch/ui` focus traps when using dialogs (outside this package)
- Expose live regions for animated numeric content (`aria-live="polite"`)
