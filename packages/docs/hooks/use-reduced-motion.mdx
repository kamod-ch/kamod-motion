## Policies

| Policy             | Behavior             |
| ------------------ | -------------------- |
| `"user"` (default) | Follow OS setting    |
| `"always"`         | Force reduced motion |
| `"never"`          | Always animate       |

Spatial presets automatically fall back to opacity-only variants when reduced motion is active.
